# Compressly

**Fast, Free & Beautiful Image and PDF Compressor** ⚡

Compress your images instantly without losing quality. Built with [Next.js / Vite + React] and modern web technologies.

![Demo](https://your-screenshot-link.com)

## ✨ Features

- Drag & drop image upload
- Real-time compression preview
- Multiple formats supported (JPG, PNG, WebP)
- Adjustable compression level
- No data uploaded to server (client-side only)
- Mobile friendly
